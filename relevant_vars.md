**Fortress**: First map of the game

# Switches

**3582 - Archipelago**: Whether or not the user is currently playing the archipelago mod
**0296 - Introchoose**: Var that controls the new game process
**3583 - IntroArchipelago**: If the player plays archipelago, this skips character select
**3584 - runItemGetSwitchID, 3585 - runItemSendSwitchID**: These control whether or not archipelago can send/receive items
